甜點訂購系統 REST API（redis-dessert）
開發中
Java 21 Spring Boot 4.1 MySQL Redis Elasticsearch MongoDB Kafka Spring AI JWT / RBAC Prometheus / Grafana Docker Compose

以「甜點線上訂購」為情境，將原先 Java Swing 桌面版甜點下單系統重新設計為企業級 RESTful API 後端服務，採用 Java 21、Spring Boot 4.1 建構，整合 MySQL、Redis、Elasticsearch、MongoDB、Kafka、Spring AI、JWT/RBAC、Prometheus 與 Grafana，實作完整的訂購、搜尋、AI 問答與系統監控能力。

  • 單品查詢（GET /api/desserts/{id}）採 Redis Cache-Aside 策略：先查 dessert:item:{id}，命中直接回傳；未命中則查 MySQL 並以 TTL 10 分鐘回寫 Redis，快取異常時記錄警告並降級至資料庫查詢，避免快取故障影響主要業務流程。
  • 下單流程（POST /api/orders）透過 Bean Validation 驗證訂單資料，後端重新依 MySQL 實際商品價格計算訂單金額（不信任前端傳入價格）；庫存扣減使用資料庫層級的單一原子 UPDATE，同時完成庫存檢查、扣減與庫存歸零自動下架，並在同一個 @Transactional 交易中逐項扣庫存，任一品項庫存不足即整筆交易回滾，避免高併發情境下的超賣問題。
  • 甜點資料採軟刪除（Soft Delete）（deleted 標記）取代實體刪除，避免歷史 OrderItem 因外鍵參照而失效；OrderItem 同時保存下單當下的商品名稱與單價快照，使歷史訂單不受後續商品改名或調價影響。補貨時若商品原本庫存 ≤ 0，而補貨後庫存 > 0，系統會自動恢復上架。
  • 搜尋功能獨立使用 Elasticsearch，提供甜點名稱模糊搜尋、價格區間與上架狀態篩選；MySQL 作為主要資料來源，甜點異動後同步更新 Elasticsearch 搜尋索引，搜尋服務故障時不影響主要 CRUD 流程。
  • AI 功能以 Spring AI + Google Gemini 建構 RAG 問答流程，使用 MongoDB Atlas Vector Store 儲存向量資料，搭配甜點、FAQ 與關鍵字規則等知識來源，提供甜點推薦與訂購相關問答；AI 對話及相關追蹤資料保存於 MongoDB。
  • 導入 Kafka 事件驅動架構，透過 OrderEvent 與 AiQaEvent 將訂單及 AI 問答相關事件發布至 Kafka，降低核心交易流程與後續事件處理之間的耦合；同一訂單以 orderId 作為 message key，維持同一訂單事件於 Kafka partition 內的順序。
  • 安全性採用 Spring Security + JWT + RBAC，透過 JWT Authentication Filter 驗證 Bearer Token，並依 ADMIN、STAFF、USER 等角色進行 URL 與 Method 層級授權；登入失敗、權限不足及業務例外皆由統一的 GlobalExceptionHandler 轉換為一致的 HTTP 錯誤格式，DuplicateNameException 與 InsufficientStockException 已分別對應 409 Conflict。
  • 以 Docker Compose 整合應用程式與 MySQL、Redis、MongoDB、Elasticsearch、Kafka 等基礎服務，並透過 Prometheus + Grafana 監控 API、訂單、搜尋、Redis、AI/RAG 與系統資源指標，建立從業務流程到基礎設施的完整可觀測性。
用戶端請求先經 JWT Authentication Filter 與 RBAC 授權，再分流至訂購（MySQL + Redis Cache-Aside、原子扣庫存）、搜尋（Elasticsearch 模糊搜尋與篩選）、AI 問答（Spring AI + Gemini + MongoDB Atlas Vector Store RAG）三大服務；訂購與 AI 服務將事件發布至 Kafka（以 orderId 作為 key 保持順序），全體服務由 Docker Compose 編排，並由 Prometheus + Grafana 統一監控
甜點快速下單系統（Java Swing 桌面應用）
已完成
Java Swing JDBC MySQL MVC

以 Java Swing 開發的甜點快速下單桌面系統，使用者可挑選品項、即時計算金額並將訂單寫入 MySQL 資料庫，採用 MVC 分層架構並具備雙層輸入驗證機制。

  • 使用 Java Swing 建立 GUI 介面，左側可選購 5 種甜點品項與數量，中間即時顯示購物車內容與金額試算。
  • 實作金額計算邏輯：自動計算小計、運費，並依滿 NT$2000 免運門檻動態顯示運費或免運提示。
  • 右側收集客戶資料（姓名、電話、LINE 帳號、下單時間），送出前於 畫面層 與 控制器層 分別進行輸入驗證，確保資料格式正確。
  • 採 MVC 分層設計：MainFrame 負責畫面與金額運算，UserController 負責商業邏輯驗證，UserDAOImpl 透過 JDBC 將訂單寫入 MySQL。
  • 以 DBConnectionPool 讀取 db.properties 管理資料庫連線設定，訂單資料寫入 dessert_db 的 orders 資料表，欄位涵蓋客戶資訊、各品項數量與金額明細。
  • 完善的例外處理：輸入不合法或資料庫寫入失敗時，皆會跳出對應的錯誤提示視窗，確保使用者能明確得知失敗原因。
資料流程：Main 啟動 → MainFrame 輸入與金額計算 → UserController 驗證 → UserDAOImpl 透過 DBConnectionPool 連線 → 寫入 MySQL orders 資料表
